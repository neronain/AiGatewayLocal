รับทั้ง OpenAI และ Anthropic API — Claude Code, Codex และ SDK ทั่วไปชี้มาที่นี่ได้ทันที

โควตารายคน ไม่ใช่รายคีย์

ออกคีย์ได้หลายใบต่อคน แต่โควตานับรวมที่ตัวคน — ทำคีย์หายแล้วออกใหม่ได้โดยไม่กระทบยอด

ข้อมูลอยู่กับคุณ

โมเดลรันบนเครื่องของคุณเอง เนื้อหาที่ถามไม่ถูกบันทึกลงบันทึกการใช้งาน

ล้มเครื่องเดียวไม่ล้มทั้งงาน

ชื่อโมเดลหนึ่งชี้ได้หลายเครื่อง เครื่องที่ป่วยถูกข้ามให้เองโดยผู้ใช้ไม่รู้สึก

สำหรับนักพัฒนา

curl …/v1/chat/completions \
  -H "Authorization: Bearer <API key ของคุณ>" \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"สวัสดี"}]}'
