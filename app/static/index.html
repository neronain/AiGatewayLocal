Suitability

Judged from the registry and the test suite, not from model names. The assistant's prompt is mostly system state and grows with the deployment, so context headroom matters more here than raw capability. ตัดสินจากข้อมูลที่วัดจริง ไม่ใช่จากชื่อโมเดล

Add a quota policy

The most specific match wins: user + model > user + bundle > user > workspace + model > workspace + bundle > workspace > global. Leave a limit at 0 for unlimited.
